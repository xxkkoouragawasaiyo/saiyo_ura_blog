## ルール

- CSSは `saiyo-cta.css` を **外観 > カスタマイズ > 追加CSS** に1回だけ貼る。パーツのHTMLに `<style>` を入れない。
- パーツには「カスタムHTML」ブロックを追加してHTMLを貼る（段落ブロックに直接貼ると、タグが崩れて文字だけ残る）。
- ブロックエディター上では追加CSSが効かないため、見た目は記事のプレビュー（フロント側）で確認する。
- ASPのコードに付いている1×1画像は、テキスト素材・バナー素材を問わず消さない。
- 同じ素材の1×1画像を1記事に2回置かない（インプレッションが二重計上される）。
- 広告リンクには `referrerpolicy="no-referrer-when-downgrade"` を付ける。付けないとブラウザの標準設定でASPのリファラーがドメイン（https://saiyo-ura.com/）までしか残らず、成果がどの記事から出たか分からない。
- 公開後、開発者ツールのNetworkで `0.gif` を絞り込み、計測用画像が読み込まれているか確認する。
