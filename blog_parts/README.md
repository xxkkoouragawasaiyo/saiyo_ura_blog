## ルール

- 各パックは `<style>` を中に含む1ファイル完結（パックDと同じ形式）。ブログパーツに「カスタムHTML」ブロックを追加して丸ごと貼る。
- CSSは全パックでパックDと同一にする。同じ記事に複数パックを置いても見た目が競合しない。CSSを変える時は全パック同時に変える。
- 追加CSSには何も入れない（旧 `saiyo-cta.css` は同じクラス名でパックDを崩すため廃止。貼っていたら削除する）。
- 計測用1×1画像は比較表に入れず、パックごとの「インプレピクセル」パーツに分ける（パックD・Eと同じ）。比較表とインプレピクセルは必ず同じ記事にセットで置く。
- VCのロゴ画像（gifbanner）は画像そのもので計測されるため、インプレピクセルに入れない。A8はバナー素材・テキスト素材とも0.gifを入れる。
- 同じ素材の1×1画像を1記事に2回置かない（インプレッションが二重計上される）。
- 広告リンクには `referrerpolicy="no-referrer-when-downgrade"` を付ける。付けないとASPのリファラーがドメイン（https://saiyo-ura.com/）までしか残らず、成果がどの記事から出たか分からない。
- 公開後、開発者ツールのNetworkで `0.gif`／`gifbanner` を絞り込み、計測用画像が読み込まれているか確認する。

## パックN（neo）を置く記事の条件

- 読者の中心が **18〜29歳の未経験・微経験（第二新卒・既卒・フリーター）** の記事に限る。
- 否認条件：新卒での就職希望（学生）、29歳以上、就職・転職意思なし、過去にネオキャリアの転職サービス利用。学生・30代以上が中心の記事に置くと、成果が出ても否認されやすい。
- NG訴求：ブラック・パワハラ等の企業を貶める表現、フルリモート・フレックス・残業なし、高収入をうたう表現（LP記載の「平均113万円の年収UP」は可）。**ブラック企業系の記事（パックDのクラスタ）には置かない。**
- 成果地点はキャリアカウンセリング（WEB面談可）の実施。登録直後に面談予約まで進めてもらう一言を添える。
